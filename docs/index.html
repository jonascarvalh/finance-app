+Início

O mês inteiro em uma tela.

Saldo acumulado, entradas, saídas e o resultado do mês logo no topo. Logo abaixo, os gráficos mostram para onde o dinheiro está indo.

  • Barras comparando entradas e saídas dos últimos 6 meses.
  • Rosca de gastos por categoria. Tocar em uma fatia mostra valor e percentual.
  • Navegação entre meses, sem passar do mês atual.
−Extrato

Cada movimentação no seu dia.

As transações do mês aparecem agrupadas por dia, com o saldo de cada dia ao lado. Dá para filtrar só as entradas ou só as saídas.

  • Filtro por Todas, Entradas ou Saídas.
  • Arrastar para o lado exclui, com opção de desfazer.
  • Tocar em uma transação abre a edição.
−Nova transação

Digite os números, o app cuida da vírgula.

O campo de valor usa uma máscara de moeda: cada dígito entra como centavo. Escolha o tipo, a categoria e a data, e a validação avisa no próprio campo se faltar algo.

→ R$ 89,90
+Ajustes

Claro, escuro ou como o sistema preferir.

O tema escolhido fica salvo ao fechar o app. Para explorar os gráficos sem digitar nada, carregue seis meses de dados de exemplo com um toque.

  • Tema Sistema, Claro ou Escuro.
  • Dados de exemplo para testar o app.
  • Apagar todos os dados, com confirmação.
